A one-image front page for Tuesday 24 November 2026: 50 sourced stories, a UTC dayline, a date check, and a By the Numbers box.

Build notes:

- `src/frontpage.html` holds the page design and story text.
- `tools/render.mjs` renders the HTML to `entry.png` at 1024×1024.
- `main.ts` verifies the PNG and copies it to the harness output directory.
